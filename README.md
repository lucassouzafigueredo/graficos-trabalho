# Gráficos FP&A: add-in do Excel

Painel lateral para criar gráficos no padrão IBCS e de consultoria (cascatas, pontes empilhadas, colunas com CAGR e comparações), com variações e estilos configuráveis.

- Painel publicado: https://lucassouzafigueredo.github.io/graficos-trabalho/taskpane.html
- Instalador: [`manifest.xml`](manifest.xml)

Este repositório contém só a versão publicada (GitHub Pages). Não há nenhum dado aqui.
